# 🏢 宜蘭縣預售屋建案備查與實價登錄銷售檢索系統

本系統專為檢索與分析**宜蘭縣預售屋申報備查與實價登錄買賣交易資料庫**而設計。
資料來源整合了內政部不動產交易實價查詢服務網（`g_lvr_buildcase.xls`、`g_lvr_land_b.csv`）與經濟部商工登記資料庫，完整收錄宜蘭全縣 **577 筆建案**、**10,611 筆實價登錄成交紀錄** 與 **360 家起造建商與負責人資料**。

---

## 🌟 核心功能特點

### 1. 📈 實價登錄銷售率與成交行情深度分析
* **已售戶數與銷售比例**：精確計算各建案自公開至今之實登已售戶數、申報總戶數與去化銷售率（例如：已售 116 / 118 戶，銷售率 98.3%）。
* **單價與總價區間**：完整呈現建案之實登平均單價（萬/坪）、單價區間（最低~最高萬/坪）、平均成交總價與總價區間。
* **各戶成交明細清冊**：建案彈窗內提供該案在實價登錄上的完整各戶成交明細表（交易日期、棟別門牌、樓層、建坪、單價、總價、格局、車位）。
* **銷售進度與單價篩選**：支援篩選「熱銷 90% 以上 (接近完銷)」、「銷售 60%~89%」、「已有實登交易」、「40萬/坪以上」、「30~40萬/坪」等。

### 2. 🏛️ 宜蘭起造建商與負責人名冊資料庫
* 完整串接經濟部商工登記資料庫，收錄 360 家建商／起造公司之**法定負責人姓名、統一編號、資本額、公司地址與宜蘭推案量**。
* 頂部專屬「建商名冊」頁籤，支援依建商名稱、負責人姓名、統一編號即時搜尋。

### 3. 🧠 智慧自然排序與分區體系歸納
* **國字期數自然排序**：自動解析「第一期」與「8期」，精準按期數 1 ➔ 99 排序。
* **土地體系架構**：整合為「都市計畫內」與「都市計畫外（非都市土地）」二元選單，分區（住宅區/商業區/特定農業區）與用地（甲建/乙建/丁建）一目了然。

## 🌐 上架到網路上（免費用戶公開網址）

本系統為純前端單檔 SPA 架構（所有數據已內嵌於 `index.html`），可透過以下任一免費靜態託管服務，一鍵發布為公開網址：

### 方式一：GitHub Pages（推薦）
1. 將本資料夾推送到 GitHub 儲存庫（Repository）。
2. 進入專案的 **Settings** ➔ **Pages**。
3. Source 選擇 `Deploy from a branch`，Branch 選擇 `main` / `root`。
4. 點擊 Save，約 1 分鐘後即可獲得全球公開網址（例如：`https://your-username.github.io/yilan-housing/`）。

### 方式二：Vercel / Netlify / Cloudflare Pages（免指令）
1. 前往 [Vercel](https://vercel.com/) 或 [Netlify Drop](https://app.netlify.com/drop)。
2. 將本專案資料夾直接拖入網頁視窗。
3. 系統將自動部署並提供專屬的免費公開網址！
